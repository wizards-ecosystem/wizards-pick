# Changelog for The Wizard's Pick

This file records user-visible changes. The project uses semantic versioning.

## 0.2.0 - 2026-09-05

- Added manual, assisted, and automated command execution modes.
- Added session scope, findings, command history, and Markdown report export.
- Added context-window budgeting for the local model.
- Pinned and verified the default Ollama and GGUF downloads.
- Added owner-only local state and report permissions on POSIX systems.
- Added bounded command output capture and process-group timeout cleanup.
- Added CI, CodeQL, Dependabot, packaging checks, and trusted PyPI publishing.
